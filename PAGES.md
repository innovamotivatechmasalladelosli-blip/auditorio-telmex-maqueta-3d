# Publicación en GitHub Pages

La aplicación publicada se encuentra en la rama `gh-pages`, con los archivos compilados en la raíz. En GitHub, abre **Settings → Pages** y selecciona:

- **Source:** Deploy from a branch
- **Branch:** `gh-pages`
- **Folder:** `/ (root)`

La rama `main` conserva el código fuente y la documentación; `gh-pages` conserva la versión lista para el navegador.
