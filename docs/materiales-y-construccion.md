# Materiales y construcción

## Materiales recomendados

### Estructura y base

- MDF de 6 mm o triplay de 6–9 mm para la base modular.
- Listón de madera o perfiles ligeros para rigidizar la parte inferior.
- Tornillos pequeños, tuercas insertables o imanes para unir módulos.
- Patas de goma y asas para facilitar el transporte.

### Volúmenes y fachadas

- Foamboard de 5 mm para masas grandes y prototipos rápidos.
- Cartón gris de 1–2 mm para revestimientos y piezas planas.
- Estireno, acrílico o PET transparente para ventanas y techo desmontable.
- Madera balsa o varilla de plástico para barandales, marcos y detalles.
- Masilla ligera, primer y pintura acrílica mate.

### Piezas 3D

- PLA para mobiliario, señalización, columnas, luminarias y piezas repetitivas.
- PETG para piezas delgadas que necesiten más resistencia.
- Boquilla de 0.4 mm como punto de partida; usar capas finas solo en detalles visibles.
- Etiquetas de pieza y orientación de impresión dentro de `blender/parts/`.

### Iluminación y movimiento

- Tiras o módulos LED de 5 V.
- Resistencias, cables, conectores y un interruptor oculto.
- Arduino Nano o ESP32 solo si se quiere programar iluminación o movimiento.
- Servomotores pequeños únicamente para una demostración sencilla de las plataformas; no son necesarios en la primera versión.
- Acrílico difusor, papel vegetal o plástico esmerilado para suavizar la luz.

## Orden de fabricación

1. Cortar y unir la base modular.
2. Construir el volumen exterior sin detalles.
3. Probar el techo desmontable y el acceso al interior.
4. Fabricar sala, gradas y escenario como módulos separados.
5. Instalar cableado antes de cerrar fachadas.
6. Añadir ventanas, señalización, barandales y mobiliario.
7. Pintar por familias de material, no pieza por pieza.
8. Colocar etiquetas y documentar cada módulo con fotografías.

## Presupuesto preliminar

El costo dependerá del tamaño final y de las herramientas disponibles. Como guía de planeación, separar el presupuesto en cuatro bolsas: **base y estructura**, **fachadas y acabados**, **impresión 3D**, e **iluminación/electrónica**. Antes de comprar, hacer un prototipo de 30 × 30 cm y ajustar el consumo real de foamboard, MDF, filamento y pintura.

## Riesgos y soluciones

- **Deformación:** usar base modular y refuerzos inferiores.
- **Techo frágil:** hacerlo desmontable en acrílico o PETG, con marco perimetral.
- **Demasiado detalle:** priorizar silueta, accesos y sala; dejar mobiliario fino para el final.
- **Piezas que no encajan:** agregar tolerancias y hacer una prueba de unión antes de fabricar todo.
- **Calor o cables visibles:** usar LED de baja potencia y canaletas ocultas.
- **Medidas inciertas:** no fijar piezas definitivas hasta completar la hoja de verificación.

## Versión escolar de bajo costo

Para una maqueta escolar, la selección predeterminada cambia a materiales de papelería: cartón cascarón o cartón gris para la base, cartón pluma/foamboard para volúmenes, cartulina opalina para revestimientos, papel batería o cartón corrugado para gradas, acetato de carpeta para el vestíbulo, palitos de madera para barandales, foamy para zonas oscuras y pinturas acrílicas escolares. El MDF, el acrílico rígido, la impresión 3D y la cortadora láser quedan como opciones avanzadas, no como requisitos.

La base recomendada se reduce a 80 × 60 cm para que el proyecto sea fácil de transportar a la escuela. Puede dividirse en dos placas de cartón cascarón reforzadas por debajo con tiras de cartón. Para pegar, usar pegamento blanco en superficies grandes y silicón frío o caliente con supervisión adulta en uniones puntuales. No hace falta fabricar cada butaca: se pueden representar por filas con tiras de cartulina y reservar los detalles para el frente, la cubierta y las gradas.
