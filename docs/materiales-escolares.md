# Materiales escolares para la maqueta

## Lista principal

- 2 piezas de cartón cascarón o cartón gris para una base de aproximadamente 80 × 60 cm.
- Cartón pluma de 5 mm para el volumen principal y los muros.
- Cartulina opalina gris para simular concreto.
- Cartulina negra o foamy negro para el plinto y zonas profundas.
- Acetato transparente de carpeta para el vestíbulo de vidrio.
- Papel batería, cartón corrugado fino o tiras de cartulina para gradas.
- Palitos de madera o brochetas para barandales y soportes.
- Papel albanene o vegetal para difuminar iluminación.
- Pinturas acrílicas escolares: gris claro, gris oscuro, negro, blanco, azul grisáceo y café.
- Pegamento blanco, cinta doble cara, regla metálica, lápiz, borrador, cúter y tijeras.
- Opcional: foamy de colores, plastilina, hilo, LEDs pequeños y una pila de 3 V.

## Material por parte

- **Base:** cartón cascarón doble.
- **Plinto:** capas de cartulina negra y cartón gris.
- **Volumen ovalado:** cartón pluma con costillas de cartón.
- **Cubierta:** cartulina gris montada sobre costillas curvas de cartón.
- **Vestíbulo:** marco de cartulina y acetato.
- **Nervaduras laterales:** tiras delgadas de cartulina gris.
- **Gradas:** tiras escalonadas de papel batería o cartón.
- **Butacas:** marcas repetidas con plumón o pequeñas tiras, sin intentar recortar miles de sillas.
- **Plaza:** cartulina gris con juntas dibujadas.
- **Vegetación:** papel verde, esponja o pequeños trozos de foamy.

## Reglas para que se vea limpio

Cortar siempre sobre una base protegida y con regla. Hacer una plantilla antes de repetir una pieza. Pintar las piezas planas antes de pegarlas. Quitar el exceso de pegamento con un palillo. Mantener el mismo tono de gris en todas las piezas que representan concreto. Dejar la cubierta desmontable con pestañas o pequeños imanes solo si ya se cuenta con ellos; si no, usar cinta doble cara reposicionable.

## Tamaño escolar

A escala 1:200, cada metro real equivale a 5 mm. El escenario de referencia de 33 × 24 m se representa aproximadamente como 16.5 × 12 cm. En una base de 80 × 60 cm conviene representar el edificio, la explanada frontal y solo una franja de estacionamiento; no todo el terreno real.
